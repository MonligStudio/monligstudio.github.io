# monligstudio.github.io

Monlig Studio'nun herkese açık sayfaları (GitHub Pages):

- `/inkstep/` — Inkstep tanıtım
- `/inkstep/privacy` — gizlilik politikası (Google OAuth onay ekranı ve mağazalar bu adresi kullanır)
- `/inkstep/terms` — kullanım koşulları
- `/app-ads.txt` — Google reklam yayıncı doğrulaması (silme)

Uygulamanın kodu ayrı ve gizli repoda (`MonligStudio/Inkstep`). Uygulamanın
topladığı veri değişirse (yeni alan, yeni hizmet sağlayıcı) gizlilik
politikasını da güncelle.
